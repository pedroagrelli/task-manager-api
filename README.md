# Task Manager API 🚀

API REST desenvolvida em Java utilizando Spring Boot para gerenciamento de tarefas.

## 📌 Funcionalidades

* Criar tarefas
* Listar tarefas
* Atualizar tarefas
* Deletar tarefas
* Marcar tarefa como concluída

## 🛠 Tecnologias utilizadas

* Java 17
* Spring Boot
* Spring Data JPA
* H2 Database
* Gradle
* REST API

## ▶️ Como executar o projeto

```bash
./gradlew bootRun
```

A aplicação iniciará em:

```
http://localhost:8080
```

## 📡 Endpoints

### Listar tarefas

GET /tasks

### Criar tarefa

POST /tasks

### Atualizar tarefa

PUT /tasks/{id}

### Deletar tarefa

DELETE /tasks/{id}
